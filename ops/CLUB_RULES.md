# Club Rules & Policies

## Discovery & Visibility
- **PUBLIC**: Discoverable in search and viewable by all users.
- **PRIVATE**: Not discoverable; requires direct link or invite to view (future).

## Join Policies
- **OPEN**: Anyone can join instantly.
- **APPROVAL**: Users must request to join; Owner/Admin must approve.
- **INVITE**: Users can only join via an invite code (future).

## Permissions
| Action | OWNER | ADMIN | MEMBER |
|--------|-------|-------|--------|
| Delete Club | Yes | No | No |
| Change Settings | Yes | Yes | No |
| Approve Members | Yes | Yes | No |
| Host Club Game | Yes | Yes | Yes |
| View Members | Yes | Yes | Yes |

## Moderation
- Owners are responsible for their club's content and member behavior.
- (Future) Reported clubs will be reviewed by platform admins.
