# NoriJjak Game Rules

## Visibility & Discovery
- **Public**: Anyone can find the game via search and filtering.
- **Private**: Hidden from search; only accessible via direct link or by entering an **Invite Code**.

## Join Policies
- **Open**: Any onboarded user can join instantly until capacity is reached.
- **Approval**: Users must request to join; the Host must manually approve or deny the request.

## Private Games & Invitations
- Private games require an **Invite Code** to join.
- Codes are generated by the Host and have a configurable `maxUses`.
- Entering a valid Invite Code allows the user to join (subject to `joinPolicy` and `capacity`).

## Capacity & Waitlist
- When **Approved** participants reach `capacity`, new joiners are placed on a **Waitlist**.
- If an Approved participant leaves, the oldest Waitlisted participant is automatically promoted.
- Promotion follow the `joinPolicy`:
    - If Open: Participant becomes `APPROVED`.
    - If Approval: Participant becomes `REQUESTED` and host is notified.

## Cancellation & Permissions
- Only the **Host** can update or cancel a game.
- Host can approve or deny join requests.
- Host can generate and revoke invite codes.
- Participants can leave at any time. Host cannot leave (must cancel).
