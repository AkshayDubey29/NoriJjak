# Ratings Rules & Eligibility

NoriJjak uses a structured rating system to build trust and ensure high-quality matches.

## Eligibility Policy

### 1. Player Ratings
- **Who can rate**: The game host and all approved participants.
- **Who can be rated**: Other approved participants and the host of the same game.
- **When**: Only after the game state is marked as `COMPLETED`.
- **Constraint**: One rating per rater -> ratee per game. Self-rating is strictly prohibited.

### 2. Venue Ratings
- **Who can rate**: Any approved participant or host of a game that was held at the venue.
- **When**: After the game is `COMPLETED`.
- **Constraint**: One rating per venue per game session.

### 3. Club Ratings
- **Who can rate**: Approved members of the club.
- **When**: Anytime after joining.
- **Constraint**: One rating per club per user (total).

## Feedback Structure
- **Score**: Integer from 1 to 5.
- **Categories (Optional)**: Structured tags like `SKILL`, `MANNER`, `PUNCTUALITY`.
- **Comment (Optional)**: Max 300 characters.

## Edit Window
- Ratings can be updated within **24 hours** of submission. After that, they are locked to prevent retrospective manipulation.
